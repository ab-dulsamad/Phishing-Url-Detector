Understanding the 6 Phishing Detection Checks

01

@ Symbol Deception

RFC 3986 treats everything prior to @ as user authentication info. Attackers write http://paypal.com@evil.com to trick victims while routing to evil.com.

02

Excessive URL Length (> 100 Chars)

Long URLs conceal the true landing domain beyond the address bar edge on smartphones and embed convoluted obfuscation strings.

03

Direct IP Address Hostnames

Legitimate organizations publish named domains with registered TLS certificates. Cybercriminals deploy raw IPs to bypass domain registration takedowns.

04

Excessive Subdomain Segments (≥ 5)

Attackers concatenate multiple subdomains (e.g. bank.com.login.verify.attacker.com) to mimic authenticity on truncated displays.

05

Punycode (xn--) Homoglyph Spoofing

Internationalized Domain Names translate visually lookalike Cyrillic/Greek characters into ASCII starting with xn-- to impersonate trusted brands.

06

Insecure HTTP Protocol

Plaintext HTTP transmits credentials unencrypted without server authentication, enabling eavesdropping and Man-in-the-Middle credential interception.
